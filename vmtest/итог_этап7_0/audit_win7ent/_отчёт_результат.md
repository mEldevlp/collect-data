**Синхронизация времени: ВКЛЮЧЕНА**

С кем: с NTP-серверами из параметра NtpServer, тип NTP:

- time.windows.com

Служба времени сейчас не запущена. В Windows 10 и 11 она запускается по событию или по расписанию, поэтому текущий источник и время последней синхронизации могут быть недоступны.

Текущий источник времени по данным службы, w32tm /query /source:

**Параметры, по которым сделан вывод, с учетом групповых политик**

| Параметр | Значение |
|---|---|

| Служба W32Time сейчас запущена | нет |
| Тип синхронизации, Type | NTP |
| NTP-серверы, NtpServer | time.windows.com,0x9 |
| NTP-клиент включен, NtpClient Enabled | 0x1 |
| Синхронизация с хостом Hyper-V, действует только на виртуальных машинах, VMICTimeProvider Enabled | 0x1 |
| Часть параметров задана групповой политикой | нет |

**Состояние службы и время последней успешной синхронизации, w32tm /query /status**
